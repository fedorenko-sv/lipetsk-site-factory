# OBLIK · «Ателье света»

Демо для владельца: **[открыть сайт](http://127.0.0.1:3033/demo/detailing)** на этом компьютере. [Рабочий промпт и критерии](../design/detailing-motion.md). Предыдущая [кинематографичная версия](detailing-cinematic.md) остаётся на своей ветке и порту 3032.

## Что смотреть

1. Внизу первого экрана выберите **«Линия крыла»**, затем **«Поверхность»**. Это один немой 15-секундный фильм с тремя главами: у каждой свой операторский ход, в конце — растворение в следующую. Можно остановить кадр и переключать планы на паузе. При запрете движения или экономии данных доступны те же три фотографии без запроса MP4.
2. Прокрутите до **«Всё видно на свету»**. На тёплой бумаге нарисован профиль купе; полоса инспекционного света и линия отражения идут по нему в такт естественной прокрутке. Чертёж читается и при отключённой анимации.
3. В **«Начните с главного»** выберите капот, кузов, диски или салон. Выбранную поверхность показывает штриховка, привязанная к пикселям фотографии. **«Крупный план»** показывает материал, а **«Выбрать время»** передаёт эту услугу в форму.
4. В **«Работаем вручную»** показана кромка плёнки в руках мастера. В иллюстрациях услуг используется короткое раскрытие кадра. К форме записи декоративное движение не применяется.

## Что сделано технически

- Два оригинальных синтетических кадра: заднее крыло того же графитового купе и укладка прозрачной плёнки. Новые материалы — локальные WebP; фотографии иллюстрируют концепт, не представляют портфолио реального ателье.
- Два H.264-файла по 15 секунд / 24 fps, без звука, с метаданными в начале файла. 1920×1080 — 4,48 МБ, 1280×720 — 1,75 МБ. Миниатюры трёх глав вместе весят около 6,3 КБ. Видео останавливается за пределами экрана и на скрытой вкладке.
- Компонент PhotoFilm показывает реально воспроизводимую главу и управляет временем видео. Слайды остаются доступны при блокировке autoplay. LightStudy подключает GSAP/ScrollTrigger локально по мере приближения к сцене; смена системной настройки движения снимает эффект. ZonePlate использует один кадрированный прямоугольник для фотографии, линий и кнопок.
- Это режиссированный фильм из изображений и интерактивная карта, а не вращаемая 3D-модель: у кузова нет подвижных дверей или капота. Для настоящего 3D этап и требования описаны в [предыдущем отчёте](detailing-cinematic.md).
- Реальная демо-заявка использует существующий API. Запись только в локальную тестовую базу; уведомление фиксируется recording-адаптером.

## Повторный запуск

Из корня этой ветки, Node 22 и Docker Desktop:

~~~powershell
npm ci
npm run db:test:up
npm run build
npm run preview:detailing
~~~

По умолчанию это порт 3033. Для другого свободного порта задайте `DETAILING_PREVIEW_PORT` и для сервера, и для системной проверки. Каждый порт использует отдельную синтетическую БД на loopback. Для пересборки фильма при изменении кадров установленный FFmpeg с libx264 должен быть в PATH: `node scripts/render-detailing-film.mjs`. Обычный запуск сайта не требует FFmpeg. В новом терминале `npm run test:detailing:system` проверяет путь браузер → HTTP → PostgreSQL → запись о доставке.
