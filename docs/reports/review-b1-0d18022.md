## Дефект

RU_PHONE_RE использует общий класс whitespace. В JavaScript этот класс включает Unicode-разделители строк U+2028/U+2029 и BOM U+FEFF. Текущая проверка управляющих символов их не отсекает.

Дополнительная независимая проверка вставила каждый из трёх символов внутрь номера:

| Вставка | Ожидалось | Фактически |
| --- | --- | --- |
| U+2028 LINE SEPARATOR | null | Номер принят и нормализован |
| U+2029 PARAGRAPH SEPARATOR | null | Номер принят и нормализован |
| U+FEFF BOM | null | Номер принят и нормализован |

Первые два прямо нарушают запрет переносов строк. BOM не входит в разрешённое форматирование. Нужен явный список допустимых символов вместо общего класса whitespace.
