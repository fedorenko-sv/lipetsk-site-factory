# Мобильная загрузка и фотосерии Stay — 18.11.2026

Пакет поверх BASE 59df276, ветка codex/six-prototypes, PR #5. Изменяется подача и доставка ресурсов; HTTP, цена, сохранение и смысл демонстрационной заявки сохранены.

## Что сделано

- Два дома Stay получили разные архитектурные образы: A-frame «Сосна» и горизонтальный панорамный «Лесной». Собственные фотографии в главной, каталоге и карточке; по два кадра на дом.
- Ручная галерея: выбор нужного фото, диалог, оборачивание предыдущего/следующего кадра, стрелки клавиатуры, Escape, возврат фокуса, мобильный режим и reduced motion. Отказ изображения показывает полезное сообщение и не закрывает путь к заявке.
- Три новых изображения созданы встроенным image_gen; исходный экстерьер A-frame сохранён. Все кадры обозначены как визуальные концепты. Полные промпты, размеры, SHA-256 и конечные пути: [манифест Stay](../../public/demo-assets/prototypes/stay/manifest.json).
- Пять шрифтов преобразованы из TTF в WOFF2: 872120 → 220308 байт файлов (−74,7%). Проверено точное равенство Unicode cmap и hmtx; кириллица, исходники и OFL сохранены. Фактическое сетевое сокращение ниже, поскольку сервер уже сжимал TTF.
- Шесть главных, витрина и внутренние визуальные блоки используют штатный next/image с sizes. Первый видимый кадр витрины получает высокий приоритет; ниже расположенные изображения остаются отложенными. Новый runtime-пакет не добавлялся.
- Медиареестр и презентационные компоненты отделены от SiteConfig и цен. Идентификатор выбранного дома передаётся в прежний Booking; ночи, гости, наличие и оплата не рассчитываются.

## Метод измерений

Локальный production-сервер 127.0.0.1:3035; Playwright Chromium, viewport 390×844, DPR 2, touch/mobile emulation, CPU ×4. Сеть: RTT 100 ms, download 200 KiB/s, upload 100 KiB/s через CDP. Новый браузерный контекст на страницу, browser cache выключен; до серии выполнен отдельный прогрев страниц и ресурсов сервера.

Baseline — один прогон исходного приложения 59df276; после — три прогона итоговой сборки, в таблице медиана и диапазон LCP. Трафик — CDP encodedDataLength, включая HTTP-заголовки. CLS считается по окнам с исключением recent input. Никакого ввода/скролла до фиксации LCP. Это локальная лаборатория, не Lighthouse score, не реальные мобильные устройства и не полевой p75.

При первой оптимизации lazy-загрузка видимого кадра витрины ухудшила LCP; по замеру возвращены eager для первых карточек и высокий приоритет для первой. Промежуточный результат сохранён, худшие значения не выдаются за окончательные.

Использованные определения и API: [LCP](https://web.dev/articles/lcp), [Playwright CDPSession](https://playwright.dev/docs/api/class-cdpsession), [Chrome Network emulation](https://chromedevtools.github.io/devtools-protocol/tot/Network/). Поведение next/image сверено с документацией установленной Next 16.4.6 в node_modules/next/dist/docs/.

## Воспроизведение

Из папки portfolio, Node 22; production preview оставить работающим во втором терминале.

~~~powershell
npm ci
npm run db:test:up
npm run build
npm run preview:portfolio
~~~

Новые галерейные тесты стандартным tracked-конфигом (отдельный тестовый сервер на 3021):

~~~powershell
npx playwright test tests/e2e/stay-gallery.spec.ts
npm run verify:demo-routes
npm run test:portfolio:system
~~~

Лабораторный профиль с бюджетом относительно архивного baseline:

~~~powershell
New-Item -ItemType Directory -Force work/portfolio/presentation-polish | Out-Null
Copy-Item docs/reports/presentation-polish/baseline.json work/portfolio/presentation-polish/baseline.json
$env:PERF_LABEL='current'
$env:PERF_RUNS='3'
$env:PERF_COMPARE_LABEL='baseline'
npm run measure:demo-performance
~~~

Для одного прогона без сравнения убрать PERF_COMPARE_LABEL и задать PERF_RUNS=1. Отчёт создаётся в игнорируемой work/portfolio/presentation-polish. Измеритель разрешает только loopback и возвращает ненулевой код при ошибке страницы/запроса, переполнении или провале бюджета шрифтов. Тайминги не превращены в нестабильный CI-порог.

Преобразование шрифтов без установки инструментов в глобальное окружение:

~~~powershell
python -m pip install --target work/portfolio/presentation-polish/font-tools -r scripts/requirements-fonts.txt
$env:PYTHONPATH=(Resolve-Path work/portfolio/presentation-polish/font-tools).Path
python scripts/optimize-demo-fonts.py
~~~
