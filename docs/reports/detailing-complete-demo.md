## Результат

У OBLIK 14 страниц: кинематографичная главная, каталог, шесть содержательных описаний услуг, цены, ателье, памятки/вопросы, визит, запись и политика. Корневая витрина показывает OBLIK и два существующих сценария Auto/Beauty.

Каталог фильтруется по задаче; выбор остаётся в URL и восстанавливается кнопкой браузера «Назад». Страница услуги показывает состав, процесс, ограничения, уход и две связанные программы. Цена берётся из той же конфигурации, что форма. Из каталога, прайса или описания выбранная услуга передаётся в отдельную запись. Неизвестный serviceId выдаёт 404, недопустимый параметр записи возвращает человека к выбору существующих программ.

Общая навигация работает на всех страницах; мобильное меню использует нативный dialog. В WebKit обнаружена и исправлена особенность фокуса после Escape: кнопка открытия теперь получает фокус явно. Редакторская типографика отделена от размеров внутри формы.

Фотографии открываются коротким движением при прокрутке; содержимое доступно и без JavaScript. Переключение prefers-reduced-motion немедленно снимает текущее движение. Существующий немой фильм и интерактивная карта кузова сохраняют свои проверки.

## Архитектура

- Новый слой content.ts добавляет тексты и связи к существующему SiteConfig, без параллельного прайса.
- Информационные страницы рендерятся сервером; динамический параметр услуги допускает только собранные маршруты.
- Небольшие клиентские компоненты отвечают за меню, появление карточек и подключение общего BookingFlow. Новый CMS и зависимости не добавлены.
- API, PostgreSQL, идемпотентность и outbox не менялись. Локальный просмотр использует отдельный порт 3034 и собственную синтетическую БД.
- Подробное содержание и порядок реализации: [рабочий план](../superpowers/plans/2026-11-15-detailing-complete-demo.md).

## Запуск

Из корня этой ветки, Node 22 и работающий Docker Desktop:

~~~powershell
npm ci
npm run db:test:up
npm run build
npm run preview:detailing
~~~

Адрес: http://127.0.0.1:3034/demo/detailing. Для другого свободного порта задайте DETAILING_PREVIEW_PORT и при запуске, и при системной проверке. Сервер доступен на этом компьютере, пока работает процесс просмотра.
