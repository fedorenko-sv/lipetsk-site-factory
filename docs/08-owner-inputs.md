# Входные данные владельца

Архитектуру, тесты на синтетике и интерфейс можно разрабатывать без этих данных. Отсутствие значения блокирует только зависимый live-шаг.

| Вход | Текущее решение | Когда нужен |
| --- | --- | --- |
| Канал администратора | Выбирается отдельно для каждого заказчика; Telegram, почта или CRM через адаптер | При запуске конкретного клиента |
| Получатель, провайдер и учётные данные выбранного адаптера | Значений нет; общего обязательного канала нет | В защищённое окружение, не в чат/Git |
| Бренд/логотип | Нейтральное «Авто · Демо» | Перед клиентским демо |
| Услуги/цены/адрес/контакт | Синтетические данные с маркировкой, без чужих материалов | Перед персонализацией/live |
| Оператор, политика, согласие | Демонстрационная заглушка, не юридический документ | До приёма реальных данных |
| Хостинг, регион хранения, доступы к БД | Локальный Docker для разработки | До production развёртывания |
| Домен/публикация | Не выполняется автоматически | Отдельное поручение на публикацию |
| Хранение/удаление/backup | 7 дней синтетика; live-предложение 90 дней ещё не утверждено | До live |
| Разрешение внешней аналитики | Выключена | До включения внешнего сбора |

Создание нового закрытого Git-репозитория разрешено текущим запросом. Выдача доступов посторонним, создание платных сервисов, массовая рассылка и приём персональных данных этим действием не выполняются.

Необходимый пакет для production на одном шаге: канал и его безопасная настройка, реальные услуги/контакты, оператор и утверждённые тексты, выбранные окружение/БД/регион и срок хранения. Пока он не собран, итог может быть demo-ready, но не release-ready.
