# Что мы строим и где посмотреть

**Состояние на 06.11.2026:** ранее запущенный preview-процесс сейчас отсутствует, Docker engine недоступен. Адреса ниже относятся к локальному просмотру при запущенном окружении. Постоянной публичной ссылки пока нет. [План до законченного демо](11-complete-demo-plan.md).

Строим переиспользуемую основу сайтов для малого бизнеса. Первый вариант — автосервис, второй — салон красоты. Для следующего заказчика меняются услуги, цены, контакты, оформление и получатель заявок; общий механизм формы и сохранения используется повторно.

Путь посетителя: прайс → услуга и желаемое время → контакт и согласие → заявка получена. Администратор вручную подтверждает время.

## Открыть на этом ПК

- [Автосервис](http://127.0.0.1:3030/demo/auto).
- [Салон красоты](http://127.0.0.1:3030/demo/beauty).
- [Витрина двух примеров](http://127.0.0.1:3030).

Выбери услугу, будущую рабочую дату и время. Для отправки введи только синтетический номер +70000000000, имя оставь пустым и отметь согласие. После отправки появится номер заявки — она действительно сохраняется в тестовой базе.

Сейчас уведомление записывается через recording: настоящее сообщение заказчику не отправляется. Реальный Telegram/email/CRM подключается отдельно под конкретного клиента.

Это локальный просмотр: сервер оставлен запущенным на этом компьютере, доступен при работающем Docker и preview-процессе.
