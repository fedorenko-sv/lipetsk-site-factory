## Проверенные технические основания

- [Next.js: установка](https://nextjs.org/docs/app/getting-started/installation) и [Route Handlers](https://nextjs.org/docs/app/api-reference/file-conventions/route): App Router и серверный HTTP endpoint в одном проекте.
- npm registry на момент старта вернул next 16.4.3 и react 19.3.1. В опубликованной документации фигурирует 16.4.5: документация не является источником установленной версии. Фактические зависимости определяет lockfile.
- [PostgreSQL: ограничения](https://www.postgresql.org/docs/current/ddl-constraints.html): уникальные ограничения обеспечивают защиту от конкурирующих повторов.
- [Telegram Bot API](https://core.telegram.org/bots/api#sendmessage): отправка в известный разрешённый chat_id через серверный адаптер. Реальные сообщения не отправлялись.
- [Защита веток GitHub](https://docs.github.com/en/repositories/configuring-branches-and-merges-in-your-repository/managing-protected-branches/about-protected-branches): доступность защиты закрытого репозитория зависит от тарифа. Состояние настройки фиксируется по фактическому ответу GitHub.

## Неизвестное не превращаем в факт

Услуги, цены, бренд и адрес — синтетический материал. Владелец уточнил: канал получения заявок определяется пожеланиями каждого заказчика. Telegram — один из возможных адаптеров. Продакшен-хостинг, регион хранения и политика — отдельный вход в live-режим. Готовность к продаже рабочего внедрения нельзя подтвердить только локальной сборкой.
