## Дефект

src/server/config/guards.ts:
- строка 97: missing.unshift(path.basename(current));
- строка 108: path.resolve(real, ...missing.reverse()).

unshift уже сохраняет порядок «родитель → имя файла». Дополнительный reverse меняет путь назначения при нескольких отсутствующих сегментах.

Воспроизведено настоящим export CLI. Во внешнем временном каталоге создать папку export.csv; путь missing-parent/export.csv отсутствует. Запрос экспорта туда должен отказать. Сейчас процесс завершается 0 и пишет файл export.csv/missing-parent.

Свидетельства: docs/reports/hermes-3390577-evidence/export-probe.json и export-probe.mjs.txt. Скрипт диагностики использует фильтр по несуществующему site, поэтому экспортирует только заголовок без контактов.

## Исправить

- Сохранить порядок отсутствующих сегментов и точное имя назначения.
- Фактический разрешённый путь не должен превращаться в другой файл/каталог.
- Если родительской папки нет, CLI честно отказывает без создания постороннего файла; автоматическое создание папок не добавлять.
- Сохранить realpath/junction-защиту, нормализацию .., wx/no-overwrite и запрет экспорта внутрь checkout.
- Не менять контракт API, зависимости и уже исправленную очередь.
