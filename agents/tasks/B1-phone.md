## Сигнатура

export function normalizePhone(input: unknown, mode: "demo" | "live"): string | null

Функция возвращает нормализованный телефон или null. Не бросает исключение на неверном пользовательском вводе, не читает env, не логирует вход, не делает сетевые вызовы.

## Правила

1. Допускаются строки в форме +7XXXXXXXXXX либо 8XXXXXXXXXX и форматирование пробелами, скобками, дефисами. Внешние пробелы обрезаются.
2. Обе формы преобразуются в +7XXXXXXXXXX. Цифр исходного номера после удаления форматирования должно быть ровно 11.
3. Номер без + с начальной 7, десятизначный номер без префикса, +8, другие страны, буквы, добавочные номера, несколько плюсов, пустой ввод и нестроковые значения отклоняются.
4. Внутри строки допустимы обычные и неразрывные пробелы. Переносы строк и управляющие символы отклоняются.
5. В live номер +70000000000 отклоняется. В demo принимается только этот синтетический номер после нормализации; остальные отклоняются.
6. Кроме запрета синтетического номера в live, не добавлять собственный справочник операторов/регионов и недокументированные ограничения.

## Тесты

Использовать встроенные node:test и node:assert/strict; импорт функции из ../../src/server/leads/phone.ts. Node.js 22.23.2 поддерживает запуск с удалением типов. npm ci для этих двух файлов не требуется.

Обязательные случаи:

- +7 (999) 123-45-67 в live → +79991234567.
- 8 999 123 45 67 в live → тот же результат.
- Внешние и неразрывные пробелы в допустимом номере.
- Пустая строка, null, undefined, число, объект → null.
- Короткий/длинный номер, номер другой страны и 10 цифр без префикса.
- Начальная 7 без +, +8, лишний +, буквы или добавочный номер.
- Перенос строки внутри номера.
- +70000000000 в demo → этот номер; в live → null.
- 8 (000) 000-00-00 в demo → +70000000000.
- Обычный номер в demo → null.

Сначала написать тесты и убедиться, что положительные сценарии действительно падают; при необходимости использовать минимальную заглушку функции, затем реализовать поведение. Команда:
node --experimental-strip-types --test tests/backend/phone.test.mjs

В отчёте указать фактическое число тестов и итог команды. Не писать, что выполнены lint/build/интеграционные проверки, если они не запускались. Не менять package.json ради команды.
